# 🎮 Tic-Tac-Toe

A simple and interactive **Tic-Tac-Toe game** built with **HTML5, CSS3, and JavaScript**. The game supports two-player gameplay, automatically detects wins and draws, and allows players to restart the game from the browser.

## 🚀 Live Demo

👉 [Play Tic-Tac-Toe](https://nandani27-garg.github.io/Tic-Tac-Toe/)

## ✨ Features

- 🎮 Two-player gameplay
- ❌ Player X starts the game
- ⭕ Player O takes the next turn
- 🏆 Automatic win detection
- 🤝 Automatic draw detection
- 🔄 Reset/restart game option
- 📱 Responsive and simple UI
- ⚡ Instant game-state updates

## 🛠️ Technologies Used

## 🎯 How to Play

1. Open the [Live Demo](https://nandani27-garg.github.io/Tic-Tac-Toe/).
2. Player **X** makes the first move.
3. Players take turns placing their marks on the board.
4. The first player to get three marks in a row wins.
5. If all cells are filled without a winner, the match ends in a draw.
6. Use the **Reset** button to start a new game.

### 🏆 Winning Conditions

A player wins by getting three of their marks in:

- A horizontal row
- A vertical column
- A diagonal
