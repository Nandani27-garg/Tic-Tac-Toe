# 🎮 Tic Tac Toe Game

A simple and interactive **Tic Tac Toe game** built using **HTML, CSS, and JavaScript**. This project provides a clean and responsive interface where two players can play Tic Tac Toe directly in the browser.

## 🎯 How to Play

1. Player **X** starts the game.
2. Players take turns placing their marks on the board.
3. The first player to get three marks in a row wins.
4. If all cells are filled without a winner, the game ends in a draw.
5. Click **Reset Game** to start a new match.

Clone the repository:
